Ingestion

Two specialist agents extract structured records from uploaded documents into shared ReconciliationState.

  • IngestionSpecialist: Opus (images), Haiku (Excel/CSV), Sonnet (PDF) → PaymentRecord.
  • BankStatementSpecialist: Sonnet (PDF, LLM-first), Haiku (text/CSV), structured parsers for XLSX → BankEntry.
  • Routes to human review when no records extracted or average confidence < 0.5.
  • Implementation: backend/app/agents/sdk/stages/

Normalisation

Deterministic FX service converts every record to base currency and computes tolerance bounds — no LLM call.

  • FX cache pre-warmed for every (currency, date) pair; records processed concurrently via asyncio.gather.
  • Outputs NormalisedRecord with invoice-rate and settlement-rate MYR amounts.
  • tolerance_low / tolerance_high include SWIFT estimates and FX_VARIANCE_BUFFER_PCT (1.5%).
  • Skips to report when nothing remains to match.

Matching

MatchingSpecialist (Sonnet) scores candidates after deterministic pre-filters.

  • Phase 1: date window ±5 days, amount within tolerance band; rapidfuzz pre-scoring in parallel.
  • Phase 2: composite score — amount 40%, date 20%, reference 30%, payer 10%.
  • Phase 3: LLM reasoning on reference, payer, and residual variance.
  • 0.5 ≤ confidence < 0.75 → review queue; borderline 0.45–0.65 skips extra escalation call.

Report

ReportSpecialist synthesises the final ReconciliationReport and Excel export.

  • Summary stats: matched, uncertain, unmatched counts and total value in base currency.
  • Exception narratives for unmatched lines; variance explanations on every match.
  • Excel workbook: Summary, Matched, Exceptions, Audit Log sheets.
  • Routing: backend/app/agents/sdk/routing.py — confidence thresholds enforced in Python, not by the LLM.
