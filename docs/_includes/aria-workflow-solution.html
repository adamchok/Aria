Upload

Finance teams submit payment proofs (images, PDFs, Excel) plus bank data in one job.

  • NovaPay: /upload — drag proofs; attach a statement file or select a registered bank account (all pending ledger entries included).
  • API: POST /api/v1/jobs — multipart upload with payment_proofs[], optional bank_statement or bank_account_id.
  • Continuous ingest: external systems push proofs via POST /api/v1/ingest/transactions; statements land on bank accounts separately.

Extract

Specialist agents turn unstructured documents into typed PaymentRecord and BankEntry rows.

  • Payment proofs: vision-first for images; structured parsers for PDF/Excel/CSV with LLM fallback.
  • Bank statements: LLM-first PDF extraction; pdfplumber fallback; XLSX/CSV via column-aware parsers.
  • Records with extraction confidence < 0.5 route to human review; field-level flags below 0.7 surface in the UI.

Normalise

Every payment proof is converted to the job base currency (default MYR) with an FX-aware tolerance window.

  • Live and historical FX rates at invoice date and settlement date.
  • Estimated SWIFT charges deducted per corridor.
  • 1.5% variance buffer (FX_VARIANCE_BUFFER_PCT) defines tolerance_low / tolerance_high for matching.

Match

Three-stage matching combines deterministic filters with LLM reasoning and a composite confidence score.

  • Filter: date window ±5 days, amount within tolerance band.
  • Score: amount 40%, date 20%, reference 30%, payer name 10%.
  • ≥ 0.75 → auto-match; 0.50–0.74 → review queue; < 0.50 → exception / unmatched.

Report

ARIA synthesises a reconciliation narrative and exports an audit-ready Excel workbook.

  • Summary cards: matched, uncertain, unmatched counts and total value in base currency.
  • Variance explanations in plain language for every line item.
  • Excel export: Summary, Matched, Exceptions, and Audit Log sheets.

Review

Uncertain matches (confidence 0.50–0.74) never auto-confirm — finance officers decide with full context.

  • NovaPay: /jobs/{id}/review — side-by-side proof vs candidate bank lines.
  • Actions: confirm, reject, or manual match with bank entry picker.
  • Every decision is logged with reasoning chain, confidence, and optional reviewer note.
